# Dell BMC Tools

Welcome to the Dell BMC Tools documentation section. This section covers Dell's Baseboard Management Controller (BMC) tools and utilities.

## Available Tools

### RACADM (Remote Access Controller Admin)
RACADM is Dell's command-line utility for managing Dell PowerEdge servers remotely. It provides comprehensive management capabilities for Dell BMCs.

- [Get Command Reference](RACADM/get.md) - Retrieve system information and settings
- [Set Command Reference](RACADM/set.md) - Configure system settings and options
- [Subcommands](RACADM/subcommands/) - Additional RACADM subcommands and utilities

## Getting Started

To use RACADM, you'll need:
- A Dell PowerEdge server with iDRAC
- Network access to the iDRAC interface
- Appropriate administrative credentials

For detailed command syntax and examples, explore the documentation links above.
