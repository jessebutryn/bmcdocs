# RemoteConsole

Launches the remote console of the managed system.

## Syntax

### Single System OOB
```
saa -i <IP or host name> -u <username> -p <password> -c RemoteConsole
```

## Options

None.

## Examples

### OOB
```bash
[SAA_HOME]# ./saa -i 192.168.34.56 -u ADMIN -p PASSWORD -c RemoteConsole
```
