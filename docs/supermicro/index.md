# Supermicro BMC Tools

Welcome to the Supermicro BMC Tools documentation section. This section covers Supermicro's Baseboard Management Controller (BMC) tools and utilities.

## Available Tools

### SUM (Supermicro Update Manager)
SUM is Supermicro's comprehensive firmware update and management utility for Supermicro servers.

- [Complete Command Reference](SUM/) - All SUM commands and options

### SAA (SuperServer Automation Assistant)
SAA provides automation capabilities for Supermicro server management and configuration.

- [Complete Command Reference](SAA/) - All SAA commands and options

## Getting Started

Supermicro BMC tools support multiple access methods:
- **OOB (Out-of-Band)**: Direct BMC network access
- **In-Band**: Local system access
- **Remote In-Band**: Remote system access through management interfaces

For detailed command syntax and examples, explore the documentation links above.
